# SoloFounder لـ ZCode

نسخة مجتمعية متوافقة مع ZCode من مشروع [SoloFounder الأصلي](https://github.com/solofounder-ai/solofounder) المرخّص بـMIT. أُعيد تنظيم المهارات لتعمل كبنية Plugin في ZCode، مع استبعاد Hooks التشغيل التلقائي وخادم المعاينة التفاعلي الأصلي.

> **الحالة:** تمت مراجعة ملفات المصدر المتاحة واختبارات الحزمة وأداة المعاينة محليًا. لم يتم بعد تثبيت الحزمة داخل تطبيق ZCode المكتبي والتحقق من ظهورها وتشغيلها هناك.

## المحتويات

- 10 مهارات ZCode لتخطيط المشاريع، تصميم المراحل، إنشاء أدوار متخصصة، البحث، TDD، التصحيح، التحقق، إدارة الاستثناءات، النماذج البصرية، وتحليل ما بعد التنفيذ.
- الأمر `/solofounder` مع دعم `$ARGUMENTS`.
- وكيل فرعي لمراجعة الجودة بصلاحية القراءة فقط.
- أداة اختيارية لعرض ملفات HTML والصور النقطية محليًا.
- تقرير أمني، إسناد للمصدر، اختبارات قابلة لإعادة التشغيل، وملف بصمات SHA-256.

## تغييرات الأمان

- لا توجد `hooks/hooks.json` أو `.mcp.json` أو سكربتات تثبيت أو تشغيل تلقائي.
- استُبعدت Hooks الجلسة وخادم المعاينة الأصلي.
- أداة المعاينة البديلة لا تبدأ إلا يدويًا، وتستمع على `127.0.0.1` فقط، وتخدم ملفات HTML وصورًا نقطية محددة من مجلد واحد، وتقبل GET/HEAD فقط، وتفرض CSP يمنع JavaScript والاتصالات الخارجية، ولا تحتوي على WebSocket أو نقطة كتابة للأحداث.
- تظل أداة المعاينة عملية محلية؛ لا تعرض فيها محتوى لا تثق به، وأوقفها عند الانتهاء.

راجع [SECURITY-NOTES.md](SECURITY-NOTES.md) للاطلاع على الأدلة وحدود الفحص.

## التثبيت من GitHub داخل ZCode

1. افتح Workspace في ZCode.
2. انتقل إلى **Settings → Plugins → Create → Add marketplace**.
3. أضف المستودع: `https://github.com/totoabdennour-ai/solofounder-zcode`.
4. ثبّت وفعّل `solofounder-zcode` من Personal marketplace.
5. تحقق من ظهور المهارات العشر في **Settings → Skills**.
6. ابدأ محادثة جديدة واستخدم `$using-solofounder <goal>` أو `/solofounder <goal>`.

قبل نشر المستودع يمكنك تثبيته محليًا بإضافة المجلد الذي يحتوي `marketplace.json` كمصدر Marketplace محلي.

## أمثلة الاستخدام

- `$using-solofounder خطط لنظام عمليات وخدمة عملاء لمطعم.`
- `/solofounder صمّم ونفّذ لوحة تحكم داخلية آمنة.`
- `$tdd-methodology` لتطبيق منهجية الاختبار أولًا.
- `$systematic-debugging` لتتبع السبب الجذري.
- `$live-research` للتحقق من المعلومات التقنية الحالية.
- `$verification` للتحقق بالأدلة قبل إعلان الاكتمال.

## تشغيل المعاينة الاختيارية

تحتاج إلى Node.js لهذه الأداة فقط، ولا تحتاج إلى تثبيت حزم npm:

```bash
node plugins/solofounder-zcode/tools/preview-server.mjs --dir ./path/to/preview-files
```

ضع `index.html` والصور الاختيارية في المجلد نفسه. سيطبع الخادم عنوان localhost. أوقفه عبر `Ctrl+C`. هذه معاينة ثابتة وليست نظام التصويت التفاعلي الموجود في المصدر الأصلي.

## الاختبارات

```bash
python tests/validate_bundle.py
python tests/test_preview_server.py
```

يتطلب اختبار المعاينة Node.js. الاختباران لا يحتاجان مكتبات Python خارجية.
