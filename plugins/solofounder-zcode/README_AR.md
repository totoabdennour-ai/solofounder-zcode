# SoloFounder لـ ZCode — النسخة المجتمعية

تكييف لبنية مشروع SoloFounder المفتوح المصدر والمرخّص MIT للعمل كـPlugin في ZCode. هذه ليست نسخة رسمية من أصحاب المشروع الأصلي.

## المحتويات

- عشر مهارات بصيغة ZCode مع بيانات `name` و`description`.
- أمر `/solofounder` ووكيل فرعي لمراجعة الجودة بصلاحية القراءة فقط.
- ملفات مساعدة لتنفيذ المراحل وتتبع الأسباب الجذرية.
- خادم معاينة ثابت اختياري لملفات HTML والصور النقطية. يستمع على `127.0.0.1` فقط، ويقبل GET/HEAD فقط، ويمنع JavaScript والموارد الخارجية عبر CSP، ولا يحتوي على WebSocket أو كتابة للأحداث.

## ما استُبعد

لم نضمّن Hooks الجلسة الأصلية أو خادم المعاينة التفاعلي أو سكربتات إدارة عملياته أو ملفات Claude/Cursor أو إعدادات MCP. تفعيل الـPlugin لا يشغّل خادم المعاينة تلقائيًا، ولا توجد سكربتات تثبيت أو lifecycle.

## التثبيت

أضف مستودع Marketplace من **Settings → Plugins → Create → Add marketplace** ثم ثبّت `solofounder-zcode`. للتطوير المحلي، أضف المجلد الذي يحتوي `marketplace.json` كمصدر محلي.

## الاستخدام

- `$using-solofounder <goal>` لبدء سير العمل أو استئنافه.
- `/solofounder <goal>` لبدء سير عمل مقسّم إلى مراحل.
- استخدم مهارات مثل `$flow-composer` و`$role-generator` و`$live-research` و`$tdd-methodology` و`$systematic-debugging` و`$verification` بشكل مستقل.

## المعاينة الاختيارية

تتطلب Node.js ولا تتطلب حزم npm:

```bash
node tools/preview-server.mjs --dir ./path/to/preview-files
```

ضع `index.html` والصور المدعومة في المجلد نفسه. أوقف الخادم عبر Ctrl+C. لا تدعم هذه النسخة التصويت أو جمع الملاحظات التفاعلية عمدًا.
